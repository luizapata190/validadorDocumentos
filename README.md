# 🔏 Notario Digital - Monorepo Web3

Este repositorio contiene la arquitectura completa de la aplicación **Notario Digital**, una solución descentralizada para la certificación e inmutabilidad de documentos mediante la huella digital criptográfica (SHA-256).

El proyecto está diseñado bajo una estrategia **Multichain** para comparar y desplegar soluciones en diferentes ecosistemas blockchain.
